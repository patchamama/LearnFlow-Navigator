Chapter 3

Control Flow and Functions

So far every program has run top to bottom, one line after another. Control flow lets a program make decisions and repeat work.

if / elif / else

age = 20

if age < 13:
    print("child")
elif age < 20:
    print("teenager")
else:
    print("adult")

Python checks each condition in order and runs the first block whose condition is True.

Loops

for loops walk through a sequence; while loops repeat as long as a condition holds:

for fruit in ["apple", "banana", "cherry"]:
    print(fruit)

count = 3
while count > 0:
    print(count)
    count -= 1

Functions

A function packages a piece of logic under a name so it can be reused with different inputs:

def greet(name):
    return f"Hello, {name}!"

print(greet("Ada"))      # Hello, Ada!
print(greet("Linus"))    # Hello, Linus!

name is a parameter — a placeholder for whatever value is passed in when the function is called. return sends a value back to the caller.

Default values
def greet(name="friend"): lets you call greet() with no arguments and still get a sensible result: "Hello, friend!".

Putting it together

def is_even(n):
    return n % 2 == 0

for number in range(1, 6):
    label = "even" if is_even(number) else "odd"
    print(f"{number} is {label}")

That's the core of Python: variables hold values, control flow decides what runs, and functions turn logic into something reusable. Everything else in the language builds on these three ideas.
