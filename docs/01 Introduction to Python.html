Chapter 1

Introduction to Python

Python is a general-purpose programming language known for readable syntax and a huge ecosystem of libraries. It is used for web backends, data analysis, automation scripts, and teaching programming itself — it's often the first language people learn.

Why Python?

  • Reads close to plain English — fewer symbols to memorize than many other languages.
  • One official interpreter, available on Windows, macOS, and Linux.
  • A massive standard library plus third-party packages for almost anything (web, data science, automation).

Your first program

Every Python tutorial starts the same way. Save this as hello.py and run it with python3 hello.py:

print("Hello, World!")

The print() function writes text to the screen. No semicolons, no boilerplate — this is a complete, runnable program.

Try it
Change the text inside the quotes and run the file again. Python re-reads the file from the top every time you run it.

How code is organized

Python uses indentation — not curly braces — to group lines of code together. A block starts after a colon (:) and every line inside it must be indented by the same amount (4 spaces is the convention):

if 2 > 1:
    print("Two is bigger than one")
