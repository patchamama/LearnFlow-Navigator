Chapter 2

Variables and Data Types

A variable is a name that points to a value. Python figures out the type of a value automatically — you never declare it up front.

name = "Ada"
age = 36
is_student = False

The built-in types you'll use daily

TypeExampleMeaning
int42Whole number
float3.14Decimal number
str"hello"Text
boolTrue / FalseYes/no value
list[1, 2, 3]Ordered, changeable collection
dict{"key": "value"}Key-value pairs

Checking a type at runtime

x = 10
print(type(x))   # <class 'int'>

x = "now a string"
print(type(x))   # <class 'str'>

This is called dynamic typing: the same variable name can point to values of different types over its lifetime. The type belongs to the value, not to the variable.

Working with lists

fruits = ["apple", "banana", "cherry"]
fruits.append("date")
print(fruits[0])        # apple
print(len(fruits))      # 4
Note
Python indexes start at 0, so fruits[0] is the first item, not the second.
